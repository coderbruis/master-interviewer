# 评分与复习规则

## 成绩定义

脚本使用 A、B、C、D 四档成绩：

- A（回答正确）：核心结论、关键机制和适用边界都正确，表达可以有小瑕疵。
- B（基本正确）：主结论正确，机制基本完整，但遗漏一个重要边界或工程细节。
- C（部分正确）：包含有效知识点，但关键链路缺失，或存在会影响判断的概念混淆。
- D（回答错误）：核心结论错误、主要因果关系颠倒，或用户明确表示不会。

“当前未作答”不是成绩。用户在作答前请求参考答案、跳题或中断时，不应伪造 D。

## 评分证据

只评价用户实际说出的内容：

1. 提取明确正确的判断。
2. 找出决定答案成立与否的关键缺口。
3. 区分知识错误、表达不清和缺少例证。
4. 根据最严重且最核心的问题定档。

不要因为答案短就自动降级；如果问题只要求一个判断，简洁且正确可以是 A。也不要因为答案很长就提高成绩。

## 帮助的处理

- 用户请求提示时，给最小提示并继续等待回答。
- 使用提示后答对，可以记录成绩，但反馈中说明答案依赖了提示。
- 请求参考答案但尚未作答时，记录为未作答并安排后续复查，不记成错误答案。
- 用户明确说不会时，可记 D，因为已经形成了有效的掌握度证据。

## 复习优先级

优先复习：

1. D 且权重高的知识点。
2. C 且连续暴露同类错误的知识点。
3. B 中遗漏关键边界的知识点。
4. 长期未复查的高权重 A。

复习题应换一种场景或问法，避免用户只记住原题答案。连续答对后逐步延长复习间隔；再次答错则缩短间隔并保留重点标记。

## 反馈示例

```text
结论：部分正确。

答对的部分：你指出了事务隔离级别会影响并发现象。

纠正：范围锁并不是“锁住整张表”。它锁定的是索引记录及相邻区间，实际范围取决于访问路径和查询条件。

参考答案：……
```

引用用户内容时只摘取必要短句，避免把整段回答原样重复一遍。
